# 수업 시작 전, 이것만 준비해 주세요

이 안내는 `lecture-prism`을 받기 **전**에 보는 자료입니다. 강의가 시작되기 10분 전까지 해두면 충분합니다.

## 먼저 준비할 것

- Codex 또는 Claude Code 중 하나를 고르고, 본인 계정으로 로그인합니다.
- 컴퓨터에서 수업용으로 쓸 위치를 정해 **빈 폴더 하나**를 만듭니다. 문서 폴더나 바탕 화면처럼 나중에 찾기 쉬운 곳이면 됩니다. 폴더 이름은 `lecture-prism`으로 해도 좋습니다.
- Codex 또는 Claude Code에서 방금 만든 빈 폴더를 **작업 공간·프로젝트 폴더로 먼저 선택**한 뒤 채팅을 시작합니다. 폴더를 Finder나 탐색기에서 보기만 한 상태는 아직 준비가 끝난 것이 아닙니다.
- GitHub 계정은 지금 만들지 않아도 됩니다. 이 수업의 `lecture-prism`은 공개 저장소라 로그인 없이 복제할 수 있습니다.
- 아래 프롬프트는 이미 시작한 코딩 에이전트의 채팅창에 붙여넣습니다. 터미널에 직접 입력하지 않습니다.

## 코딩 에이전트에 붙여넣기

```text
나는 AI 자동매매 시스템 구축 수업을 준비하고 있어. 지금 대화를 시작한 현재 작업 공간에 공개 GitHub 저장소 https://github.com/dragon1086/lecture-prism 를 안전하게 받아줘.

조건:
1. GitHub 로그인·계정 생성·토큰·API 키·브로커·계좌 설정은 요구하거나 만들거나 읽지 마. 이 저장소는 공개 저장소라 GitHub 로그인 없이 복제해줘.
2. 현재 작업 공간의 실제 경로와 비어 있는지 먼저 확인해줘. Git이 준비되어 있으면 저장소를 현재 작업 공간 안에 받아줘. 이미 파일이 있거나 저장소가 이미 받아져 있다면 삭제하거나 덮어쓰지 말고 상태를 알려줘.
3. 복제가 끝나면 프로젝트 루트가 현재 작업 공간에서 바로 보이는지 확인하고, `lecture/exercises/수강생_붙여넣기_프롬프트_파트3.md` 파일의 위치만 알려줘.
4. 아직 Python 실행·패키지 설치·코드 수정·실데이터 연결·OAuth·브로커·계좌 설정은 하지 마.
5. 복제할 수 없으면 내가 직접 터미널 명령어를 치게 하지 말고, 막힌 이유와 다음에 필요한 최소 조치만 짧게 알려줘.
```

## 프로젝트 환경 준비

저장소를 받은 뒤, 아래 프롬프트를 한 번 더 붙여넣습니다. 이 단계는 강사와 수강생 모두가 합니다. 수강생이 직접 `activate`하거나 Python 경로를 외울 필요는 없습니다.

```text
현재 작업 공간의 lecture-prism 프로젝트에서 수업용 Python 환경을 준비해줘.

조건:
1. 현재 작업 공간이 lecture-prism 프로젝트 루트인지 확인해줘.
2. 설치되어 있는 Python 중 3.10 이상인 것을 찾아 사용해줘. 전역 `python3`가 3.10 미만이면 그대로 쓰지 말고, 사용할 수 있는 3.10·3.11·3.12·3.13 중 하나를 찾아줘. 3.10 이상이 전혀 없으면 설치를 시도하지 말고 필요한 조치만 알려줘.
3. 프로젝트 루트에 `.venv`가 없으면 만들고, 이미 있으면 삭제하지 말고 Python 버전과 정상 작동 여부를 확인해 재사용해줘.
4. 프로젝트 루트의 `.venv`에 `requirements.txt` 전체를 설치해줘. 전역 Python이나 전역 pip에는 설치하지 마.
5. 패키지 설치 중 외부 네트워크 승인이 필요하면, 패키지 저장소에 대한 범위 제한 네트워크 승인을 요청해줘. 전역 권한 우회나 시스템 설정 변경은 하지 마.
6. 설치가 끝나면 `.venv`의 Python과 pip가 실제로 실행되는지 확인해줘. 결과에는 사용한 Python 버전과 `.venv` 경로만 짧게 알려줘.
7. 설치가 실패하면 시스템 Python이나 다른 프로젝트를 바꾸지 말고, 실패한 패키지와 이유를 알려줘. 기본 mock 수업은 패키지 설치 실패와 별개로 계속할 수 있다고 설명해줘.
8. 아직 `main.py`나 다른 프로그램은 실행하지 마.
```

`requirements.txt`를 모두 설치해도 실데이터·Discord·OAuth·브로커가 자동으로 켜지는 것은 아닙니다. 실제 연결 설정과 프로필 선택은 수업 중 안전한 분기에서 따로 확인하고, 준비되지 않은 경우에는 mock으로 진행합니다. 실데이터나 Discord를 선택할 때도 코딩 에이전트가 필요한 도메인에만 범위 제한 네트워크 승인을 요청하게 하고, 전역 샌드박스 해제나 권한 우회를 요구하지 않습니다.

## 여기까지 끝나면

수업이 시작되면 강사가 부르는 번호의 프롬프트를 `수강생_붙여넣기_프롬프트_파트3.md`에서 복사합니다. 첫 실행은 수업 중에 함께 합니다.

문제가 생기면 오류 화면을 닫지 말고 그대로 둡니다. 수업 중에 코딩 에이전트에게 다시 전달해 해결합니다.
