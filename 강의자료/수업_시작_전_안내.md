# 수업 시작 전 준비

이 안내는 `lecture-prism`을 받기 **전**에 보는 자료입니다. 강의 시작 10분 전까지 준비하면 됩니다.

## 먼저 할 일

- Codex 또는 Claude Code 중 하나를 고르고 본인 계정으로 로그인합니다.
- 컴퓨터에서 수업용 **빈 폴더 하나**를 만듭니다. 문서 폴더나 바탕 화면처럼 찾기 쉬운 곳이면 됩니다.
- 빈 폴더를 Codex 또는 Claude Code의 **작업 공간·프로젝트 폴더로 먼저 선택**한 뒤 채팅을 시작합니다. Finder나 탐색기에서 폴더만 연 상태는 준비가 끝난 것이 아닙니다.
- 공개 저장소를 받는 데 GitHub 계정은 필요하지 않습니다.
- 아래 프롬프트는 이미 시작한 코딩 에이전트의 채팅창에 붙여넣습니다. 터미널에는 입력하지 않습니다.

## 코딩 에이전트에 붙여넣기

```text
나는 AI 자동매매 시스템 구축 수업을 준비하고 있어. 지금 대화를 시작한 현재 작업 공간에 공개 GitHub 저장소 https://github.com/dragon1086/lecture-prism 를 안전하게 받아 줘.

조건:
1. GitHub 로그인·계정 생성·토큰·API 키·브로커·계좌 설정은 요구하거나 만들거나 읽지 마. 이 저장소는 공개 저장소라 GitHub 로그인 없이 복제해 줘.
2. 현재 작업 공간의 실제 경로와 비어 있는지 먼저 확인해 줘. Git이 준비되어 있으면 저장소를 현재 작업 공간 안에 받아 줘. 이미 파일이 있거나 저장소가 이미 받아져 있다면 삭제하거나 덮어쓰지 말고 상태를 알려 줘.
3. 복제가 끝나면 프로젝트 루트가 현재 작업 공간에서 바로 보이는지 확인하고, `lecture/exercises/수강생_붙여넣기_프롬프트_파트3.md` 파일의 위치만 알려 줘.
4. 아직 Python 실행·패키지 설치·코드 수정·실데이터 연결·OAuth·브로커·계좌 설정은 하지 마.
5. 복제할 수 없으면 내가 직접 터미널 명령어를 치게 하지 말고, 막힌 이유와 다음에 필요한 최소 조치만 짧게 알려 줘.
```

## 프로젝트 환경 준비

저장소를 받은 뒤 아래 프롬프트를 한 번 더 붙여넣습니다. 이 단계는 강사와 수강생 모두가 합니다. `activate`나 Python 경로를 외우지 않아도 됩니다.

```text
현재 작업 공간의 lecture-prism 프로젝트에서 수업용 Python 환경을 준비해 줘.

조건:
1. 현재 작업 공간이 lecture-prism 프로젝트 루트인지 확인해 줘.
2. 설치되어 있는 Python 중 3.10 이상인 것을 찾아 사용해 줘. 전역 `python3`가 3.10 미만이면 그대로 쓰지 말고, 사용할 수 있는 3.10·3.11·3.12·3.13 중 하나를 찾아 줘. 3.10 이상이 전혀 없으면 설치를 시도하지 말고 필요한 조치만 알려 줘.
3. 프로젝트 루트에 `.venv`가 없으면 만들고, 이미 있으면 삭제하지 말고 Python 버전과 정상 작동 여부를 확인해 재사용해 줘.
4. 프로젝트 루트의 `.venv`에 `requirements.txt` 전체를 설치해 줘. 전역 Python이나 전역 pip에는 설치하지 마.
5. 패키지 설치 중 외부 네트워크 승인이 필요하면, 패키지 저장소에 대한 범위 제한 네트워크 승인을 요청해 줘. 전역 권한 우회나 시스템 설정 변경은 하지 마.
6. 설치가 끝나면 `.venv`의 Python과 pip가 실제로 실행되는지 확인해 줘. 결과에는 사용한 Python 버전과 `.venv` 경로만 짧게 알려 줘.
7. 설치가 실패하면 시스템 Python이나 다른 프로젝트를 바꾸지 말고, 실패한 패키지와 이유를 알려 줘. 기본 mock 수업은 패키지 설치 실패와 별개로 계속할 수 있다고 설명해 줘.
8. 아직 `main.py`나 다른 프로그램은 실행하지 마.
```

`requirements.txt`를 설치해도 실데이터·Discord·OAuth·브로커가 자동으로 켜지는 것은 아닙니다. 연결 설정과 프로필은 강의 중 따로 확인합니다. 준비되지 않은 경우에는 mock으로 진행합니다. 실데이터나 Discord를 선택할 때도 필요한 도메인에만 범위 제한 네트워크 승인을 요청하며, 전역 샌드박스 해제나 권한 우회는 하지 않습니다.

## 선택 준비: Part 4에서 KIS 실제 수급을 볼 사람

KIS 준비는 선택입니다. 준비하지 않아도 mock과 yfinance 경로로 전략 실습을 진행할 수 있습니다. 준비한 사람은 Part 3 말미의 P3-04에서 삼성전자 한 종목의 가격과 기관·외국인·개인 순매수를 읽고, Part 4에서 수급 섹션만 바꿔 봅니다.

- 한국투자증권 Open API에서 모의투자(paper) 또는 실전(real) App Key와 App Secret을 준비합니다.
- 이 읽기 전용 실습에는 계좌번호·HTS ID가 필요하지 않습니다.
- 강사는 real 키로 실제 데이터를 시연하지만, 주문·취소·정정·잔고·계좌 API는 호출하지 않고 매매는 simulation으로 유지합니다.
- 주말·휴장일에는 실시간 값이 아니라 가장 최근 영업일 값이 나옵니다.
- 키를 채팅창·화면 공유·Git에 붙이지 않습니다. 프로젝트 폴더 바로 안의 로컬 `.env`에 본인이 직접 입력합니다.

`.env`는 코드를 넣는 파일이 아니라, 이 프로젝트가 어떤 외부 서비스를 사용할지 적어 두는 개인 설정 파일입니다. `.env.example`은 빈칸만 있는 견본입니다. 코딩 에이전트가 프로젝트 루트에 `.env.example`을 복사해 `.env`를 만들고 기본 텍스트 편집기로 열면, 수강생이 아래 두 줄에 직접 값을 넣고 저장합니다.

| 선택한 환경 | 값을 넣을 줄 |
|---|---|
| 모의투자 paper | `KIS_PAPER_APP_KEY`, `KIS_PAPER_APP_SECRET` |
| 실전 데이터 real | `KIS_REAL_APP_KEY`, `KIS_REAL_APP_SECRET` |

이 단계에는 계좌번호와 HTS ID를 넣지 않습니다. 저장 뒤 에이전트는 값 자체를 보여 주지 않고 `준비됨 / 비어 있음 / 형식 오류`만 확인합니다.

아래 프롬프트는 값을 대신 입력하지 않고 안전한 빈자리만 준비합니다.

```text
현재 lecture-prism 프로젝트에서 Part 4 KIS 수급 숫자 비교 실습 준비 상태를 점검해 줘.

먼저 `.gitignore`가 `.env`를 제외하는지 확인해 줘. `.env`는 프로젝트 폴더 바로 안에 두는 개인 설정 파일이고, `.env.example`은 빈칸이 있는 견본이라고 설명해 줘. `.env`가 없으면 `.env.example`을 복사해 만들되, 기존 파일이 있으면 삭제하거나 덮어쓰지 마.
내가 선택한 환경은 [paper 또는 real]이야. paper면 `KIS_PAPER_APP_KEY`와 `KIS_PAPER_APP_SECRET`, real이면 `KIS_REAL_APP_KEY`와 `KIS_REAL_APP_SECRET` 줄을 기본 텍스트 편집기로 열어 줘. 내가 그 두 줄에 직접 값을 입력하고 저장할게. 숫자만 확인하는 실습이라 계좌번호와 HTS ID는 필요하지 않다고 설명해 줘.
실제 값은 내가 파일을 직접 열어 입력할 테니 키·토큰을 요구하거나 채팅에 붙여넣게 하지 마. 아직 외부 API 조회, 주문·취소·정정·잔고·계좌 조회, 코드 수정은 하지 마.
```

## 준비가 끝나면

수업이 시작되면 `수강생_붙여넣기_프롬프트_파트3.md`에서 강사가 말한 번호를 복사합니다. 첫 실행은 수업 중에 함께 합니다.

IntelliJ는 필요하지 않습니다. Codex 또는 Claude Code가 현재 작업 공간의 파일과 `.venv`를 사용하므로, 수강생은 폴더 위치와 준비 프롬프트만 챙기면 됩니다.

문제가 생기면 오류 화면을 닫지 말고 그대로 둡니다. 수업 중에 코딩 에이전트에게 그대로 전달해 해결합니다.
