에이전트 기초 · 도구 호출

에이전트가 바깥 정보를 읽으려면 도구가 필요합니다

이 프로젝트에서는 LLM 호출도 입력을 보내고 결과를 받는 하나의 도구 사용입니다.

도구 호출은 거창한 기능이 아닙니다. 필요한 입력을 보내고, 돌아온 결과가 약속한 모양인지 확인하는 과정입니다.

에이전트 기초 · 결과 전달

에이전트끼리 직접 대화하지 않고 결과를 다음 입력으로 넘깁니다

키 이름과 JSON 구조를 맞춰 결과를 넘기는 것입니다.

에이전트 기초 · 자주 쓰는 방식

에이전트는 맡길 일이 다를 때만 역할을 나눕니다

방식언제 쓰나이 프로젝트에서는
순서대로 실행앞 결과가 있어야 다음 일을 시작할 때main.py의 후보 → 보고서 → 매매
나눠 조사한 뒤 편집여러 관점을 한꺼번에 모을 때여섯 분석가 → 편집 에이전트
담당자 고르기요청에 따라 고칠 곳이 달라질 때트랙 A/B/C/D에서 담당 파일 선택
검사하고 다시 고치기수정 뒤 결과를 다시 확인할 때테스트 → mock 실행 → 로그 확인
사람이 결정하기컴퓨터 설정이나 위험한 변경 전3분 뒤 예약을 등록하기 전 승인
역할을 많이 나눈다고 더 좋은 것은 아닙니다. 책임과 결과가 달라질 때만 나눕니다.
