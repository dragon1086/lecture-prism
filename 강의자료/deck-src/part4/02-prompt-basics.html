7
기본기

프롬프트 공식 — AI에게 코드를 고치게 하는 법

현재 상태 + 원하는 결과 + 유지할 제약
  • "지금은 이런데(현재), 이렇게 바꿔줘(결과), 단 이건 건드리지 마(제약)"
  • 이 구조만 지켜도 결과가 완전히 달라짐
8
비교

Bad vs Good

❌ Bad
"손절 좀 잘해줘"
✅ Good
"지금 손절은 -7%인데(현재), -5%로 바꿔줘(결과). 트레일링 스탑 로직은 그대로 두고, 바꾼 뒤 데모로 검증해줘(제약)"

차이: AI가 추측할 일이 없어짐

9
큰 그림

AI와 일하는 세 순간

순간 1
일을 시킬 때
문제를 말한다
역할을 준다
기준을 댄다
순간 2
지킬 것을 정할 때
동결을 선언한다
지어내기를 금지한다
내 의도를 설명한다
순간 3
결과를 받았을 때
고치기 전에 확인시킨다
근거를 들어 반박한다
큰 일은 나눠 시킨다
  • 공식(현재+결과+제약)이 실전에서 이 아홉 가지로 진화함

"프롬프트 엔지니어링보다 컨텍스트 엔지니어링" — Karpathy(2025) · AI에게 무엇을 보여줄지 설계하는 기술

순간 1 — 일을 시킬 때

몰라도 시킬 수 있습니다

  • 해결책 말고 문제를 말함 → "손절을 잘하고 싶어. 지금 코드 보고 방법 추천해줘"
  • 역할을 줌 → "너는 보수적인 리스크 관리자야"
  • 결과물 기준을 댐 → "끝나면 전후 비교표로 보여줘"
"궁금한 것은 너가 파일 찾아서 조사해봐. 나도 어떤 방향이 가장 효과적일지 예측을 못하겠어. 결국은 매매를 더 잘하게끔 하고 싶은데" — 2026년 3월, 강사 실제 프롬프트. 모른다고 인정해도 목적만 말하면 AI가 탐색함
