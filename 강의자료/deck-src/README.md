# 강의 슬라이드 원본 관리

`파트3_슬라이드.html`, `파트4_슬라이드.html`은 발표·공유용으로 **정적 생성된 단일 HTML**이다. 빌드할 때 모듈의 슬라이드 내용을 이 파일 안으로 실제로 복사해 넣으므로, 파일을 열면 모든 문구·이미지·CSS가 보이는 것이 정상이다. 브라우저가 여러 모듈 파일을 링크해 실시간으로 조립하는 방식은 아니다. 직접 고치지 않는다.

## 수정 순서

1. `part3/` 또는 `part4/`에서 해당 교육 단위 파일만 연다.
2. 슬라이드를 추가·삭제·이동했다면 `deck-manifest.json`의 모듈 순서와 슬라이드 ID도 함께 고친다.
3. `node 강의자료/deck-src/build-decks.mjs`로 발표용 HTML과 사람이 읽는 인덱스를 다시 만든다.
4. 수정이 수강생 행동을 바꾸면 강사용 진행 스크립트와 수강생 붙여넣기 프롬프트의 같은 ID도 확인한다.
5. 최종 HTML 전체를 1280×720으로 렌더링해 흐름·잘림·이미지 맥락을 확인한다.

## 찾는 법

- 화면의 슬라이드 ID(`P3-S01`, `P4-S01`처럼)는 최종 HTML의 `data-slide-id`와 `deck-manifest.json`에 같다. 이는 **화면을 찾기 위한 번호**다.
- 수강생 프롬프트 번호(`P3-01`, `P4-08`처럼)는 인덱스의 `연결 프롬프트` 열에서 따로 관리한다. 두 번호 체계를 섞지 않는다.
- 어떤 주제를 고칠지 모르겠으면 `part3-index.md` 또는 `part4-index.md`에서 제목을 찾고, 표시된 원본 모듈만 읽는다.
- 공통 색·글꼴·이미지 크기는 `shared/part3-head.html`, `shared/part4-head.html`에 있다.
- 페이지 번호, 과거 운영 예시 표식, 정보량 높은 이미지를 크게 보여 주는 규칙은 `shared/*-tail.html`에 있다.
