모듈 1 · 구조 질문과 단독 실행

screening.py만 따로 읽고 실행합니다

아래 문장을 코딩 에이전트에게 그대로 붙여넣습니다.

1. screening.py를 읽고 입력 → 필터 → 점수 → 최종 후보 흐름을 설명해줘.

2. 코드는 고치지 말고 python3 screening.py를 연습 데이터로 실행해줘.

3. 조건을 통과하지 못한 종목이 왜 빠졌는지 실행 로그로 확인해줘.

4. 원본 PRISM과 비교해 구현됨 / 작게 구현됨 / 아직 없음으로 나눠줘.

5. 실제 주문·계좌·API 키는 쓰지 마.

6. 마지막에 내가 후보 조건을 바꿀 때 확인할 질문 세 개를 남겨줘.

지금은 구조를 읽습니다. 조건을 고치는 실습은 파트 4에서 합니다.
