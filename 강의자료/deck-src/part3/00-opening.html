첫 실행의 기준은 보고서 분량이 아니라 다섯 단계의 연결입니다. 준비된 사람은 실데이터·선택한 보고 채널까지 확인하고, 아니면 연습 데이터로 같은 흐름을 끝까지 실행합니다.

  • 수업 시작 전 안내에 따라 복제한 lecture-prism 폴더를 엽니다.
  • Discord 또는 Telegram을 쓸 사람만 설정 프롬프트를 먼저 붙여넣고, .env에서 보고 채널과 필요한 값을 직접 입력합니다. 비밀값은 채팅에 붙여넣지 않습니다.
  • 수강생 붙여넣기 프롬프트 파일에서 P3-01 · API 키 없는 첫 성공을 찾습니다.
  • ‘코딩 에이전트에 붙여넣기’ 블록 전체를 복사해 한 번 붙여넣습니다.
  • 답변을 읽고 어느 단계까지 실행됐는지 확인합니다.
