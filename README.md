# lecture-prism

> 패스트캠퍼스 **「AI 네이티브 자동매매 시스템 구축 (실습 중심)」** 강의용 리포지토리.
> 실제 운영 중인 오픈소스 [`prism-insight`](https://github.com/dragon1086/prism-insight)를 수업용으로 작게 줄인 버전입니다.

이 수업의 목표는 "완성된 자동매매 프로그램을 바로 운영하기"가 아닙니다.
**여러분의 매매 전략을 코딩 에이전트(Claude Code·Codex)에게 말하면, 에이전트가 코드를 고치고 실행한 뒤 결과까지 확인해주는 경험**을 해보는 것입니다.
그래서 이 문서에는 터미널 명령어 대신, **코딩 에이전트에게 그대로 붙여넣을 프롬프트**를 넣었습니다.

![강의 학습 지도](docs/assets/readme/hero-learning-map.png)

---

## 수업은 이렇게 진행됩니다

미리 훑어보러 온 분들을 위한 두 번의 수업 요약입니다.

| | 무엇을 하나 | 여러분이 하는 것 |
|---|---|---|
| **파트 3** | **구독으로 AI 붙이기 + 증권사(KIS) 연동** — 첫 5분, 강의용 어댑터에 ChatGPT Plus/Pro 구독 계정을 로그인해 최신 GPT를 라이브로 연결하는 시연(실무 운영은 정식 API 키 권장)에 이어, KIS 시세 조회 → AI 에이전트 투자 판단 → 시뮬레이션 매매까지 **전체 흐름을 눈앞에서 실행**합니다 | 같은 데모를 본인 노트북에서 코딩 에이전트로 따라 실행 (기본은 mock, 매매는 전부 시뮬레이션 모드, 계좌가 없으면 조회까지만) |
| **파트 4** | 사전과제로 준비한 **내 매매 이론 3줄(진입·청산·리스크)** 중 하나를 골라, **모듈 1개를 교체(또는 추가)** 해서 내 로직이 담긴 시스템을 들고 갑니다 | 트랙 A~D 중 하나 선택 → 에이전트에게 요청 → 결과 확인 |

- **사전과제(파트4)**: 내 매매 이론 3줄 — ① 언제 사는가(진입) ② 언제 파는가(청산) ③ 얼마나 지키는가(리스크)
- **준비물**: 노트북 + Claude Code 또는 Codex + (선택) ChatGPT Plus/Pro 구독 + (선택) KIS 모의투자 App Key
- **코딩 경험은 없어도 됩니다.** 코드는 AI가 고치고, 여러분은 "무엇을 만들지"를 판단합니다.

## 0. 먼저 알아둘 것

- 리포지토리 다운로드 방법은 강사가 따로 안내합니다. 이 문서는 **이미 `lecture-prism` 폴더를 받아 코딩 에이전트에서 열어둔 상태**를 전제로 합니다.
- 긴 설명을 읽기 전에 [`START_HERE.md`](START_HERE.md)의 **5분 루트**부터 따라가도 됩니다.
- 핵심 원칙: 여러분은 "무엇을 확인하고 싶은지"만 말합니다. 설치·실행·검증은 코딩 에이전트가 대신 합니다.

## 1. 첫 5분 — "돌아간다"부터 확인하기

**API 키도, 설정 파일도, 패키지 설치도 필요 없습니다.** 아래 프롬프트를 코딩 에이전트에게 그대로 붙여넣으세요.

![처음 5분 루트](docs/assets/readme/five-minute-start.png)

```text
이 lecture-prism 프로젝트가 내 컴퓨터에서 기본 데모로 실행되는지 먼저 확인해줘.

반드시 아래 순서로 진행해줘:
1. 지금 열려 있는 폴더가 lecture-prism 프로젝트 루트인지 확인해줘.
2. 내 컴퓨터에 Python 3.10 이상이 설치되어 있는지 확인해줘.
3. Python이 없거나 버전이 낮으면, 내 운영체제에 맞는 설치 방법을 안내하고 가능한 범위에서 설치까지 도와줘.
4. 외부 패키지 설치는 일단 하지 말고, 먼저 API 키 없이 main.py 데모가 실행되는지 확인해줘.
5. 기본 데모가 성공하면 그 다음에 대시보드·실데이터·실LLM 연동에 필요한 requirements.txt 설치를 진행해줘.
6. 패키지 설치가 실패하더라도 기본 데모가 이미 성공했는지는 따로 구분해서 설명해줘.
7. 마지막에 내가 다음에 입력할 수 있는 프롬프트 3개를 추천해줘.

내가 직접 터미널 명령어를 치지 않도록, 필요한 명령은 네가 실행하고 결과를 설명해줘.
```

**성공 기준**: 에이전트가 "후보 고르기 → 분석 → 가상 매매 → 피드백 저장이 끝났고, `prism.db`에 결과가 기록됐다"고 확인해주면 됩니다.

## 2. 시스템 한 장 요약

![강의용 투자 파이프라인 지도](docs/assets/readme/pipeline-map.png)

lecture-prism은 **네 단계 흐름 + 하나의 확인 화면**입니다. 사람 투자자가 하는 일과 1:1로 이어집니다.

| 파일 | 사람으로 치면 | 수강생이 주로 바꾸는 곳 (파트4 트랙) |
|---|---|---|
| `screening.py` | "어떤 종목을 볼까?" 후보 고르기 | 거래량·시총·모멘텀 조건 → **트랙 A** |
| `analysis.py` | "이 종목, 어떻게 해석할까?" 6섹션 분석 | 분석 에이전트 프롬프트 → **트랙 B** |
| `trading.py` | "얼마나 사고, 언제 팔까?" 매매 판단 | 청산 규칙 → **트랙 C** / 리스크 상수 → **트랙 D** |
| `feedback.py` | "이번 판단에서 뭘 배웠나?" 매매일지 | 교훈을 뽑는 방식 |
| `dashboard.py` | 결과를 보는 웹 화면 (localhost:8080) | 표·카드 추가 |

이 밖에 `data_source.py`(실데이터 연결 창구), `db.py`(저장소), `blank_pipeline.py`(심화: 처음부터 만들기)가 있습니다.
그림으로 더 보고 싶으면 [`docs/architecture.md`](docs/architecture.md)를 보세요.

## 3. 학습 단계 사다리 — 설정은 `.env` 파일의 한 줄

이 저장소는 **한 단계씩 현실에 가까워지는 사다리** 구조입니다.
단계는 `.env` 파일의 `LECTURE_PROFILE` 값 하나로 바꿉니다. `.env.example`을 열어보면 아래 표의 값이 그대로 들어 있습니다.

| 단계 | `.env`에 적는 값 | 무엇이 더 켜지나 | 필요한 것 |
|---|---|---|---|
| 1️⃣ 수업 기본 | `LECTURE_PROFILE=mock` | 더미 데이터 + 가상 매매 | **없음 — `.env` 파일조차 없어도 됨** |
| 2️⃣ 실데이터 | `LECTURE_PROFILE=real_data` | + 실제 가격·거래량 (야후 파이낸스, 무료) | 인터넷 연결 (필요한 패키지는 에이전트가 설치) |
| 3️⃣ 실제 AI | `LECTURE_PROFILE=research` | + 진짜 LLM 분석·리서치 보고서 | ChatGPT 구독 **또는** OpenAI API 키 |
| 4️⃣ 모의투자 | `LECTURE_PROFILE=paper` | + 증권사 모의투자 주문 연습 | KIS 모의투자 App Key |
| 5️⃣ 실전투자 | `LECTURE_PROFILE=live` | + 진짜 주문 (수업에서는 다루지 않음) | 실전 키 + 안전장치 2개 해제 |

**중요한 안전 규칙 두 가지:**

- 어느 단계든 **필요한 키나 연결이 없으면 그 기능만 꺼지고 더 안전한 단계로 돌아갑니다.** 설정을 잘못해도 전체 흐름이 깨지지 않습니다.
- 5단계조차 `.env`의 안전장치 2개(`LECTURE_ENABLE_LIVE_BROKER`, `LECTURE_ALLOW_REAL_BROKER`)를 **직접 1로 바꾸지 않는 한 실제 주문이 절대 나가지 않습니다.**

### `.env` 파일은 언제, 어떻게 만드나

1단계(수업 기본)에서는 만들 필요가 없습니다. **2단계 이상으로 올리고 싶어지는 순간**, 아래 프롬프트를 쓰세요.

```text
.env.example을 복사해서 .env 파일을 만들어줘.
그다음 LECTURE_PROFILE 값을 real_data로 바꾸고 main.py를 실행해서,
분석에 실제 가격 데이터가 쓰였는지, 아니면 더미 데이터로 실행됐는지 구분해서 알려줘.
.env는 Git에 올라가지 않는 파일이라는 것도 확인해줘.
```

### 3단계(실제 AI)로 올리기 — 구독 어댑터 또는 API 키

이 저장소에는 **강의용 ChatGPT 어댑터**가 내장되어 있어, ChatGPT Plus/Pro 구독 계정을 로그인해 실제 LLM 분석을 켤 수 있습니다(강의·실습 편의용). **실제 서비스 운영에는 정식 OpenAI API 키가 더 안정적이고 정식으로 지원되는 경로입니다.**

![API 키와 선택 연동 안전 지도](docs/assets/readme/optional-integrations-safety.png)

```text
lecture-prism에 포함된 ChatGPT OAuth 프록시로 실제 LLM 분석을 연결해줘.

조건:
1. 프록시를 새로 만들지 말고, cores/chatgpt_proxy 안의 기본 구현을 사용해줘.
2. 필요한 패키지가 설치되어 있는지 확인하고, 부족하면 requirements.txt 기준으로 설치해줘.
3. ChatGPT Plus 또는 Pro 계정으로 최초 로그인이 필요한지 확인하고, 필요한 경우 브라우저 로그인 과정을 안내해줘.
4. 프록시가 localhost:18741에서 정상 응답하는지 연결 상태를 확인해줘.
5. .env의 LLM 관련 설정도 이 방식에 맞게 바꿔줘.
6. 그 다음 analysis.py로 005930을 분석해서 실제 LLM 응답인지 더미 응답인지 구분해줘.
7. 실패해도 기본 데모 모드는 망가뜨리지 말고, 실패 원인과 다음 행동을 설명해줘.

내가 직접 터미널 명령어를 치지 않도록 필요한 실행과 검증은 네가 해줘.
```

- 단계별 세부 스위치와 조합 예시: [`docs/runtime-profiles.md`](docs/runtime-profiles.md)
- 어떤 키가 언제 필요한지: [`docs/api-keys.md`](docs/api-keys.md) (강의 기본 실습에 필수 키는 없습니다)
- KIS 대신 키움·토스 등 다른 증권사: [`docs/broker-adapters.md`](docs/broker-adapters.md)

## 5. 내 전략 넣기 (파트 4)

처음부터 전부 바꾸려고 하지 마세요. 사전과제 3줄 중 **하나만** 골라, 아래 네 트랙 중 **하나만** 바꿔도 그날 실습은 성공입니다.
(전략이 여러 트랙에 걸쳐 있어도 괜찮습니다 — 에이전트가 한 번에 다 바꾸지 않고, 안전한 것부터 **한 트랙씩 [수정 → 검증 → 전후 비교]**를 반복합니다.)

![전략 하네스 흐름](docs/assets/readme/strategy-harness-lite.png)

| 트랙 | 내가 가진 전략 | 바꿀 파일 | 예시 프롬프트 |
|---|---|---|---|
| A | 진입 조건 | `screening.py` | "RSI 30 이하 + 거래량 3배 이상만 후보로 남겨줘." |
| B | 분석 관점 | `analysis.py` | "기술적 분석 에이전트를 볼린저밴드 하단 반등 관점으로 바꿔줘." |
| C | 청산 규칙 | `trading.py` | "목표가 +20%, 손절 -5%, 트레일링 -10%로 바꿔줘." |
| D | 리스크 관리 | `trading.py` | "최대 5종목, 현금 50% 유지, 매수 점수 5 이상으로 바꿔줘." |

가장 쉬운 시작은 [`MY_STRATEGY.md`](MY_STRATEGY.md)에 전략을 적고 이렇게 말하는 것입니다:

```text
MY_STRATEGY.md를 읽고 내 전략을 lecture-prism에 반영해줘.
내 설명이 부족하면 네가 먼저 합리적으로 정리하고,
진짜 꼭 필요한 질문만 하나만 해줘.
처음에는 Part 4 트랙 A/B/C/D 중 가장 안전한 것 하나만 골라서 수정해줘.
수정 후에는 API 키 없이 데모 모드로 실행 검증하고,
수정 전후 차이를 초보자도 이해하게 설명해줘.
실거래는 절대 하지 마.
```

> 이 리포지토리에는 **Strategy Harness Lite**가 들어 있습니다. 전략을 두루뭉술하게 말해도 에이전트가 어디를 바꾸면 좋을지 정리하고, 가장 안전한 한 파일부터 수정·검증합니다. 에이전트가 모르는 것처럼 답하면 "`docs/harness-lite.md`와 `MY_STRATEGY.md`를 먼저 읽고 Strategy Harness Lite 방식으로 진행해줘"라고 말하세요. 자세한 실습 절차는 [`lecture/exercises/part4_실습가이드.md`](lecture/exercises/part4_실습가이드.md)에 있습니다.

## 6. 안전과 제출

**실거래는 기본적으로 차단되어 있습니다.** 어떤 프롬프트를 쓰든, `.env`의 안전장치 2개를 직접 켜지 않는 한 실제 주문은 나가지 않습니다.

**GitHub 제출은 선택입니다.** 수업 성공 기준은 "내 전략이 데모 모드에서 실행되는 것"입니다. 제출이 막히면 화면 공유나 캡처로 대체합니다. 제출할 때는 커밋 전에 반드시 보안 점검부터 하세요.


| 설정이 꼬인 것 같을 때 | "내 .env를 lecture-prism 학습 단계 기준으로 점검해줘. 지금 몇 단계 상태인지, 빠진 키 때문에 꺼진 기능이 뭔지 알려줘." |
