## 25. 이제 실제 README를 열어보겠습니다

마지막으로 실제 README를 열어보겠습니다. 글을 처음부터 읽지는 않고, README에 있는 네 장의 그림만 순서대로 보겠습니다. 이 네 장을 보면 본강의에서 무엇을 만들고, 수업 뒤에 무엇이 남는지 한눈에 알 수 있습니다.

첫 번째 그림은 수업의 전체 여정입니다. 왼쪽의 ‘전략 3줄’에서 시작해, AI가 전략을 한 트랙씩 코드에 반영합니다. API 키 없이 먼저 실행해 본 뒤 실데이터와 실제 AI를 연결하고, 마지막에는 KIS 모의·실전 계좌의 매수 주문 경로까지 이어 갑니다. 그림 아래의 `.env`와 `kis_devlp.yaml`은 KIS를 연결할 때 채우는 설정 파일입니다. 실계좌 주문은 처음부터 잠겨 있어서 사용자가 안전장치를 직접 풀어야만 실행됩니다.

두 번째 그림은 완성된 시스템이 움직이는 순서입니다. 먼저 볼 종목을 고르고, AI가 자료를 분석한 뒤, 주문할지를 판단합니다. 설정이 준비되면 KIS로 매수 주문을 보내고, 판단과 주문 결과를 매매 기록으로 남깁니다. 이 기록이 다음 전략 수정의 근거가 됩니다.

세 번째 그림은 **내 전략을 넣는 네 가지 트랙**입니다. 어떤 종목을 살펴볼지 정하는 진입, AI가 무엇을 볼지 정하는 분석, 언제 팔지 정하는 청산, 얼마나 살지 정하는 리스크로 나뉩니다. 전략 전체를 먼저 읽되 코드는 한꺼번에 바꾸지 않습니다. 가장 중요한 한 영역을 수정하고 검증한 뒤, 같은 과정을 다음 영역에 반복합니다. 수업 시간에는 첫 번째 트랙 하나를 끝까지 완주하는 것이 목표입니다. A·C·D 트랙은 API 키 없이 결과를 비교할 수 있고, B 트랙의 실제 분석 문장은 LLM을 연결한 뒤 확인합니다.

네 번째 그림은 수업이 끝난 뒤의 모습입니다. `lecture-prism`은 완성된 나무가 아니라, 집에서 계속 키워 갈 작은 나무 모종입니다. 그림의 매매 로직, 모니터링, 대시보드, 텔레그램·디스코드 알림은 수업 직후 모두 완성돼 있다는 뜻이 아니라, AI와 함께 하나씩 붙여 갈 수 있는 확장 방향입니다.

정리하면, 수업이 끝날 때 남는 것은 예제 코드 한 번의 실행 결과가 아닙니다. API 키 없이도 돌아가고, 내 전략을 한 영역씩 반영할 수 있으며, 준비가 되면 KIS 매수 주문까지 연결할 수 있는 나만의 출발점입니다.
