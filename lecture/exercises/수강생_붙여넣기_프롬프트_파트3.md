# 파트 3 — 수강생 붙여넣기 프롬프트

> 명령어를 직접 외우거나 입력하지 않습니다. 아래에서 **강사가 지정한 번호 하나만** 복사해 코딩 에이전트에 붙여넣으세요.
>
> 첫 30분의 공통 목표는 **P3-01과 P3-02**입니다. 준비된 사람은 실데이터와 Discord까지 포함해 전체 흐름을 보고, 준비가 안 된 사람은 연습 데이터로 같은 흐름을 확인합니다. 어느 경로든 API 키나 계좌 연결 없이 가상 매매로 끝납니다.
>
> - **연습 데이터(기술 이름: mock)**: 실제 오늘 시장이 아니라, 같은 결과를 다시 확인할 수 있게 준비한 고정 연습 재료
> - **실데이터(real_data)**: 인터넷에서 받은 실제 가격·거래량을 쓰되, 실패하면 연습 데이터로 돌아가는 선택 경로
> - **가상 체결(simulation)**: 주문을 증권사에 보내지 않고 “이 조건이면 샀을 것”만 기록하는 연습
> - **Discord 판단 알림**: 계좌 정보가 아니라 이번 실행의 후보·분석·매매 판단을 보내는 선택 알림
> - **작업 흐름**: 후보 찾기 → 분석 보고서 작성 → 매수 시나리오 → 가상 실행 → 기록 남기기의 순서
>
> 실제 주문·브로커·계좌·시크릿은 어떤 프롬프트에서도 사용하지 않습니다. 실데이터와 Discord는 P3-01에서 준비된 사람만 선택합니다. 실제 LLM은 P3-M2 뒤에서 한 번 확인하되, 공식 Codex 로그인이 준비된 사람과 준비되지 않은 사람이 서로 다른 프롬프트로 시작해 P3-M3으로 다시 합류합니다.
>
> 모든 실행은 프로젝트 루트의 `.venv`를 사용합니다. 수강생이 직접 환경을 켜거나 Python 경로를 입력하지 않고, 코딩 에이전트가 준비된 `.venv`의 Python으로 실행하게 합니다.
>
> 수업 전 공통 준비에서 프로젝트 루트의 `.venv`에 `requirements.txt` 전체를 설치합니다. 패키지가 설치되어 있어도 실데이터·Discord·OAuth·브로커가 자동으로 켜지는 것은 아니며, 첫 실행에서 준비 상태를 확인한 뒤 안전하게 연습 데이터 경로로 돌아갈 수 있습니다.
>
> 실데이터·Discord처럼 인터넷을 쓰는 선택 기능은 코딩 에이전트가 필요한 도메인에 대한 **범위 제한 네트워크 승인**을 요청한 뒤에만 실행합니다. 전역 샌드박스를 끄거나 권한을 통째로 우회하지 않습니다.
>

```text

조건:
1. 프로젝트 루트의 로컬 `.env`가 없으면 만들고, 있으면 기존 설정은 그대로 둬. 다른 설정값·시크릿은 답변·출력·로그에 절대 포함하지 마.
```

프롬프트가 끝나면 프로젝트 폴더에서 `.env` 파일을 열고, `DISCORD_WEBHOOK_URL=""`의 따옴표 안에 **자기 웹후크 주소만** 직접 붙여넣어 저장합니다. 웹후크 주소는 코딩 에이전트 채팅에 붙여넣지 마세요. 수업 채팅·화면 공유·Git에도 넣지 않습니다.

설정이 없거나 Discord를 쓰지 않는다면 이 단계는 건너뜁니다. P3-01은 Discord 없이도 연습 데이터와 가상 체결(simulation)로 끝까지 실행됩니다.

```text

1. 코드는 수정하지 마. `.env`와 환경 변수 값도 만들거나 바꾸지 마. `LECTURE_ENABLE_LIVE_BROKER`, `LECTURE_ALLOW_REAL_BROKER`, `LECTURE_PROFILE`, `LECTURE_BROKER`, API 키, 계좌번호, 토큰 같은 시크릿 값은 출력하지 마.

3. 플래그 값을 바꾸지 마. 특히 `LECTURE_ENABLE_LIVE_BROKER`와 `LECTURE_ALLOW_REAL_BROKER`를 켜지 마.
4. 실제 주문·취소를 실행하지 마. 브로커 주문, 주문 취소, 주문 정정, 계좌 변경은 하지 마. 조회가 필요해도 먼저 코드와 문서 기준으로 configured / missing만 정리해.

10. 마지막에는 `설정 있음(configured)`과 `설정 없음(missing)`만 표로 보여줘. 값 자체, 시크릿 일부, 계좌 일부, 토큰 일부도 출력하지 마.
```
