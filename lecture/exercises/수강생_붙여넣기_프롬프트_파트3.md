## P3-04 · 선택: KIS에서 실제 숫자 한 번 받아 보기

### 코딩 에이전트에 붙여넣기

```text
컨텍스트: P3-04는 KIS의 수급 숫자 한 묶음만 확인하는 선택 단계야. 매매와 계좌 조회는 하지 않아.

내 컴퓨터에 준비된 KIS paper 또는 real 설정으로 실제 시장 데이터가 한 번 조회되는지 확인해 줘.

실행 전에 `docs/runtime-execution-preflight.md`를 읽어. 프로젝트 루트 `.venv`의 Python 3.10 이상과 `yfinance` 준비 상태를 확인하고, KIS paper 또는 real 호스트의 DNS·HTTPS를 인증 토큰 요청보다 먼저 확인해. 샌드박스에서만 DNS가 실패하면 승인된 외부 네트워크 실행인지 구분해.

먼저 `kis_market_data.py`와 관련 테스트를 읽고 가격·일별 투자자 수급만 확인하며 주문·취소·정정·잔고·계좌 기능은 호출하지 않는지 확인해. 숫자만 확인하는 경로가 맞을 때만 실행해 줘.
paper와 real 중 내가 선택해 둔 환경을 사용해. 둘 다 준비됐는데 선택이 분명하지 않으면 실행하지 말고 어느 환경을 쓸지만 물어봐. 설정값·App Key·App Secret·토큰은 일부도 출력하지 마.
필요한 KIS 도메인의 범위 제한 네트워크 승인을 받은 뒤 삼성전자 005930의 가격과 기관·외국인·개인 일별 순매수 수량을 한 번만 조회해 줘.
결과에는 KIS 환경(paper 또는 real), 데이터 원천, 종목, 기준일, 가격, 기관·외국인·개인 순매수량, 주문·취소·계좌 호출 0건을 보여 줘. 주말이나 휴장일이면 최근 영업일 값이라고 설명하고 실시간 시세라고 부르지 마.
DNS 실패·연결 시간 초과·429·5xx처럼 일시적일 수 있는 읽기 요청만 최대 2회 재시도해. 키 누락·잘못된 자격 증명은 재시도하지 마. 다른 환경으로 몰래 바꾸거나 연습 데이터 성공으로 바꾸지 마. 로그에서 확인한 원인과 다음에 고칠 한 가지만 알려 줘.
코드·`.env`·플래그를 수정하지 말고 실제 주문·취소·정정·잔고·계좌 작업을 실행하지 마.
```
