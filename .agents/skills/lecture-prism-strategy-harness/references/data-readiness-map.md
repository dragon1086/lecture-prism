# lecture-prism 자료 준비 지도

수강생이 원하는 자료마다 아래 다섯 상태 중 하나를 고른다. 어려운 기술 이름보다 “지금 무엇을 할 수 있는가”를 먼저 설명한다.

| 자료 준비 상태 | 판단 기준 | 사용자에게 할 말 | 안 되면 대신 쓰는 방법 |
|---|---|---|---|
| 지금 사용 가능 | mock 또는 현재 코드에 이미 있음 | “바로 시험할 수 있습니다.” | 기존 mock 유지 |
| 무료 연결 가능 | 공식 제공처가 있고 결제·로그인이 불필요 | “무료로 연결할 수 있지만 인터넷 상태에 따라 실패할 수 있습니다.” | 같은 모양의 mock 사용 |
| 키 또는 계정 필요 | API 키·구독·로그인이 필요 | “한 번 준비가 필요합니다. 키는 채팅이 아니라 `.env`에 넣습니다.” | 키 없이 mock 검증 |
| 사람이 넣어야 함 | 유료 리포트·캡처처럼 자동 접근이 어렵거나 부적절 | “핵심 문단을 직접 넣으면 참고할 수 있습니다.” | 예시 Markdown 사용 |
| 이번 범위 밖 | ETF·선물·코인처럼 상품 구조와 안전 조건이 다름 | “별도 확장 과제로 나눠야 안전합니다.” | 현재 주식 simulation 유지 |

## 새 데이터 연결 부품을 만들 때

- 공식 문서와 이용 조건을 먼저 확인한다.
- 이름, 제공 자료, 인증 필요 여부, 환경변수 이름을 적는다.
- 반환할 결과 모양과 기준 시각을 적는다.
- 실패 이유를 숨기지 않고 mock으로 돌아간 사실을 표시한다.
- API 키가 없어도 기본 파이프라인은 멈추지 않는다.

## 사람이 넣는 자료

- 기본 형식은 UTF-8 텍스트 또는 Markdown이다.
- 출처, 작성 시각, 종목, 핵심 문단, 중요하다고 본 이유를 함께 적는다.
- 이미지 입력이나 OCR을 쓸 수 있을 때만 캡처를 직접 읽는다.
- 유료 자료 원문과 캡처는 `student_inputs/`에 두고 Git에 올리지 않는다.
- 오래됐거나 종목이 불명확한 자료는 강한 매수·매도 근거로 쓰지 않는다.
