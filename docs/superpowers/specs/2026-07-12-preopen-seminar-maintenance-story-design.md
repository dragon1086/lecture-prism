## 목표

20분 안에서 투자 실패 경험, 근거 수집, PRISM 시즌1, 출퇴근 유지보수 루틴, 운영상 손실을 줄여 온 과정, 강의용 저장소의 첫 실행을 하나의 이야기로 잇는다. 장수를 20장에 억지로 고정하지 않고, 개인 투자 연혁 1장과 PRISM 개발 연혁 2장을 포함한 26장으로 구성한다. 기술을 나열하기보다 문상록 강사가 실제로 어떻게 관찰하고 고치고 검증하는지를 보여준다.

## 이미지

- `kospi.png`는 원본 차트와 수치를 보존하고 2018년 시작, 코로나 시기 수익, 이후 반복 손실 구간만 주석으로 표시한 별도 이미지를 만든다.
- 투자 대가의 분석팀 장면은 특정 실존 인물을 닮게 만들지 않는다. 여러 자료를 검토한 뒤 최종 판단을 내리는 팀의 역할을 보여주는 편집 일러스트로 제작한다.
- 출퇴근 유지보수는 지하철의 휴대전화, 집의 Mac mini, 운영서버, GitHub 이슈·배포가 이어지는 생활 밀착형 장면으로 제작한다. 화면에 실제 계정·서버 주소·토큰·경로는 넣지 않는다.

## 사실과 안전

- 시즌1은 2025년 3~9월, 거래 38건, 승률 44.7%, 누적수익률 371%로 표기한다. 높은 성과와 함께 매수만 AI였고 매도는 단순 규칙이었으며 소수 대세상승 종목의 영향이 컸다는 한계를 같은 장에 둔다.
- 최근 운영 개선은 PRISM Insight v2.15~v2.17 릴리스의 실시간 루프, 손절 실행, 중복 매도, 재진입 방어를 근거로 삼는다.
- 실계좌 장표는 수익 자랑보다 시뮬레이션과 실제 체결의 차이를 측정하는 검증 장치로 설명한다.
- cokacdir은 사용자가 설명한 실제 원격 개발 도구로 소개하되 내부 접속 방식과 운영서버 위치는 공개하지 않는다.

## 문체

- 슬라이드 제목은 발표자가 입으로 바로 말할 수 있는 문장으로 쓴다.
- 같은 길이의 불릿과 명사형 나열을 피한다.
- 기술 용어는 필요한 첫 장에서만 풀어 쓰고, 이후에는 쉬운 말로 반복한다.
- 성과 수치 옆에는 기간·기준·한계를 함께 적는다.

## 검증

- HTML 파싱, 26장 수, 로컬 자산 경로, 1280×720 레이아웃을 확인한다.
- 계좌번호·서버 주소·API 키·토큰·운영 경로가 HTML과 새 이미지에 들어가지 않았는지 검사한다.
- 핵심 장표를 렌더링해 텍스트 잘림과 이미지 가독성을 확인한다.
- 최종 한국어는 고유명사·수치·날짜를 보존한 채 AI식 병렬 표현과 번역투를 줄인다.
