# 파트 3 수강생 선행지식 경계 교정 설계

## 목표

파트 3 수강생은 원본 PRISM 저장소를 설치하거나 코드를 읽지 않는다. 원본과
강의용 축소판의 차이는 강사가 슬라이드로 설명하고, 수강생은 현재까지 배운
`lecture-prism` 파일만 코딩 에이전트에게 읽히고 안전하게 실행한다.

## 학습자 관점 원칙

1. 프롬프트는 해당 슬라이드까지 등장한 개념과 파일만 사용한다.
2. 후보 선정과 매수 결정처럼 아직 배우지 않은 관계를 미리 설명하게 하지 않는다.
3. 원본 PRISM 문서·파일 대조, 원본 저장소 복제, 이미지·HTML 제작은 수강생
   실습에서 요구하지 않는다.
4. 수강생이 복사할 원문은 한 곳에만 둔다. 슬라이드는 프롬프트를 축약해 다시
   싣지 않고, 붙여넣기 문서의 정확한 블록 번호를 안내한다.
5. 각 실습은 예측 → 한 번 실행 → 눈으로 확인할 증거 → 현재 진도에 맞는 한
   문장 회고로 닫는다.

## 수정 범위

### P3-S13

- `P3-M1` 블록 전체를 복사하라고 안내한다.
- 화면에는 실행 목적, 안전 조건, 확인할 결과만 보여 준다.
- 원본 PRISM 비교와 미래의 전략 변경 질문을 제거한다.

### 수강생 붙여넣기 프롬프트

- 문서 머리말의 원본 PRISM 비교 지침을 제거한다.
- `P3-M1`부터 `P3-M4`까지 원본 문서·코드 대조 요구를 제거한다.
- `P3-M1`은 `screening.py`의 입력 → 필터 → 정렬 → 후보 결과만 다룬다.
- `P3-M2`는 여섯 보고서 역할, 편집, 섹션별 폴백까지만 다룬다.
- `P3-M3`부터 매수 시나리오와 실행 안전문을 다룬다.
- `P3-M4`는 결과가 닫힌 뒤의 교훈과 기억 압축만 다룬다.
- 질문과 회고 문장은 각 모듈을 배운 직후 답할 수 있는 말로 바꾼다.
- 성공 증거에서 원본 비교표와 부가 시각물 제작을 제거한다.

### 강사용 진행 스크립트

- 원본 PRISM 비교는 강사가 앞선 이미지와 비교 슬라이드로 설명한다고 명시한다.
- 수강생은 `lecture-prism`의 해당 모듈을 읽고 실행하는 데 집중시킨다.
- 각 모듈의 행동 안내가 실제 붙여넣기 블록과 같은 학습 경계를 갖는지 맞춘다.

## 수강생이 모듈별로 알고 있는 범위

| 시점 | 이미 배운 것 | 아직 묻지 않을 것 |
|---|---|---|
| P3-M1 | 후보를 규칙으로 줄이고 순서를 정함 | 매수 방식과의 궁합, 원본 코드 차이 |
| P3-M2 | 여섯 보고서와 편집 결과 | 목표가·손절가·최종 진입 판단 |
| P3-M3 | 매수 의견 뒤에 코드 안전문이 있음 | 실거래 운영·전략 성과 평가 |
| P3-M4 | 닫힌 거래에서 교훈을 만들고 기억을 줄임 | 기억이 수익을 보장한다는 결론 |

## 검증 기준

- 파트 3 수강생 프롬프트에 원본 PRISM 저장소·파일 대조 요구가 없다.
- P3-S13이 `P3-M1` 블록 전체 복사를 분명히 안내한다.
- 각 모듈의 예상 질문과 회고는 그 시점까지 배운 내용만 사용한다.
- 강사용 스크립트가 원본 비교 설명과 수강생 실습의 역할을 구분한다.
- 덱을 다시 생성한 뒤 기존 화면 맞춤·전체 화면 이미지 기능을 유지한다.
- 관련 문서 계약 테스트와 기본 mock 실행이 통과한다.
