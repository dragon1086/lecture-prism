# 파트 3 모듈 시작 질문과 참여 방식 설계

## 목적

비전공자 수강생이 기능 설명을 듣기 전에 실제 투자자의 망설임을 먼저 느끼게 한다. 네 모듈은 모두 “오늘 이 종목을 사도 될까?”라는 한 판단을 서로 다른 책임으로 나눠 답한다.

1. 어떤 종목을 볼 것인가
2. 무엇을 확인할 것인가
3. 실제로 주문할 것인가
4. 과거 경험을 어떻게 반영할 것인가

## 확정 질문

| 모듈 | 시작 질문 | 담당 책임 |
|---|---|---|
| 1 | 어제는 강세장, 오늘은 약세장입니다. 후보를 같은 기준으로 골라도 될까요? | 시장 국면과 후보 선별 |
| 2 | 이 종목을 사기 전에, 어떤 정보까지 확인하고 싶으세요? | 여섯 분석 근거 |
| 3 | AI가 사라고 하면, 그대로 주문해도 될까요? | AI 의견과 코드 안전문 |
| 4 | 어제 손절한 종목이 오늘 다시 떴습니다. 다시 사도 될까요? | 기록·기억과 재진입 판단 |

## 참여 방식

수강생의 입을 여는 것과 매 모듈에서 같은 짝 대화를 반복하는 것은 다르다. 수강생이 이미 가진 경험과 그 시점에 제공된 근거에 맞춰 활동을 바꾼다.

- 모듈 1: 20초 개인 판단 뒤 60초 짝 대화. 시장이 바뀌었을 때 기준을 유지할지 말한다.
- 모듈 2: 사고 싶은 종목을 하나 떠올리고 필요한 정보 세 가지를 적은 뒤 옆 사람과 비교한다.
- 모듈 3: 구체적인 판단표를 먼저 보여 준다. `BUY 8점`, 현재가 `70,000원`, 목표가 `77,000원`, 손절가 `63,000원`, 손익비 `1.0`, 코드 최소 손익비 `1.5`를 보고 `주문한다 / 보류한다`에 투표한다. 실행 결과 `주문 0건`을 확인한 뒤 자기 전략의 금지선 하나를 말한다.
- 모듈 4: `바로 다시 산다 / 하루 더 본다 / 조건을 다시 확인한다` 중 하나를 고르고 이유를 말한다. lecture-prism은 같은 실행의 즉시 재진입만 막고 다음 날 자동 금지 규칙은 없다는 현재 구현을 공개한다.

## 슬라이드 변경

파트 3은 38장을 유지한다.

- P3-S07, P3-S14, P3-S31은 시작 질문 제목만 확정 문장으로 바꾼다.
- P3-S21은 텍스트가 정확한 HTML 판단 사례 슬라이드로 교체한다. 이미지 생성으로 숫자나 한글을 넣지 않는다.
- 기존 P3-S21~P3-S29는 P3-S22~P3-S30으로 한 장씩 이동한다.
- 기존 P3-S30 전환 슬라이드는 삭제한다. 장중 감시·체결 확인·피드백 준비는 P3-S37의 보조 운영 그림에서 다시 설명하므로 중복이다.
- 이동한 슬라이드의 주석 ID, 페이지 번호, manifest, index를 모두 맞춘다.

## 강사용 스크립트

- 모듈 1만 기존 60초 짝 대화를 유지한다.
- 모듈 2는 `정보 세 가지 적기 → 옆 사람과 비교`로 바꾼다.
- 모듈 3은 `사례 확인 → A/B 투표 → 실행 결과 → 내 안전선 한 문장`으로 바꾼다.
- 모듈 4는 `세 선택지 고르기 → 이유 한 문장`으로 바꾼다.
- 네 모듈의 `짝 대화 뒤 lecture-prism 기준선`은 활동 종류에 맞춰 `수강생 판단 뒤 lecture-prism 기준선`으로 통일한다.
- 모듈 4 기준선에는 다음 날 재진입 자동 금지 규칙이 아직 없다는 사실을 추가한다.

## 유지할 경계

- 수강생은 원본 PRISM 저장소를 클론하거나 비교하지 않는다.
- 수강생 프롬프트의 마지막 세 질문은 에이전트가 답하지 않는다.
- 실제 주문은 보내지 않는다.
- 모듈 3 사례는 교육용 고정값이며 실제 종목 추천이 아니다.
- 파트 3은 구조 확인과 단독 실행, 파트 4는 전략 수정이라는 경계를 유지한다.

## 검증 기준

- 파트 3은 정확히 38장이다.
- 네 확정 질문이 슬라이드와 강사용 스크립트에 각각 한 번 이상 존재한다.
- 강사용 스크립트에는 네 가지 서로 다른 참여 방식이 존재한다.
- P3-S21에 `BUY 8점`, `70,000원`, `77,000원`, `63,000원`, `손익비 1.0`, `최소 1.5`, `주문한다`, `보류한다`가 보인다.
- P3-S21은 실제 추천이 아닌 교육용 사례임을 표시한다.
- 기존 PRISM 매매 이미지와 비교·프롬프트 슬라이드는 P3-S22~P3-S30에 빠짐없이 남는다.
- 대표 렌더에서 제목·사례 숫자·선택지가 잘리거나 겹치지 않는다.
