# README 나무 모종 성장 메시지 설계

## 목표

`lecture-prism`을 완성품이 아니라 수강생이 AI와 함께 계속 키워 갈 **나무 모종**으로 설명한다. 수업 직후의 결과물과 장기적인 확장 가능성을 한 장의 그림과 짧은 글로 이해하게 한다.

## 핵심 메시지

> 완제품을 받는 것이 아니라, 계속 키워 갈 모종을 가져갑니다.

`prism-insight`도 작은 시스템에서 시작해 운영 경험을 먹고 자랐다. 수강생 역시 `lecture-prism`을 출발점으로 삼아 매매 로직, 모니터링, 대시보드, 텔레그램·디스코드 알림을 자기 방식으로 하나씩 가꿀 수 있다.

## 이미지 구성

- 형식: 가로형 README 인포그래픽, 기존 README 이미지와 같은 어두운 남색 배경과 청록·보라·주황 포인트
- 뿌리: `API 키 없이 시작하는 lecture-prism`
- 줄기: `전략 하네스 · 안전장치`
- 네 가지 가지: `매매 로직`, `모니터링`, `대시보드`, `텔레그램·디스코드 알림`
- 나무의 결실: `점점 안정적인 나만의 시스템`
- 하단 문구: `AI와 함께, 한 가지씩 가꿉니다`
- 한글은 이미지 모델이 직접 생성하며 별도 글자 합성을 하지 않는다.
- 개인 정보, 계좌 정보, API 키, 수익률 숫자, 수익 보장 표현은 넣지 않는다.

## README 배치와 문장

`수업이 끝나면 남는 것` 다음에 `수업 뒤에는 직접 키워 갑니다` 절을 추가한다. 이미지 뒤에는 비전공자도 이해할 수 있는 두 문단만 둔다. 첫 문단은 모종 비유를 설명하고, 두 번째 문단은 네 가지 확장 방향과 한 번에 하나씩 검증한다는 운영 원칙을 설명한다.

기존 하네스 설명은 `전체 전략 해석 → 우선순위 결정 → 한 영역 수정·검증 → 다음 영역 반복`으로 유지한다. 수업 시간의 첫 트랙 완주는 최소 성공 기준이지 하네스의 영구적인 한계가 아님을 명시한다.

## 발표 자료 연결

README 미리보기 슬라이드의 마지막 항목을 `수업 뒤에도 계속 자라는 모종`으로 바꾼다. 발표 원고 25절에서는 KIS 연결 설명 뒤에 모종 비유를 붙여, 수업 결과물이 끝이 아니라 각자의 유지보수 출발점임을 말한다.

## 검증 기준

- README에 로컬 이미지가 정확히 4장 있고 모든 경로가 존재한다.
- README, 슬라이드, 발표 원고에 `나무 모종`, 네 가지 확장 방향, `한 영역씩`이라는 의미가 일치한다.
- 단일 HTML을 다시 만들고 외부 이미지·스타일·스크립트 의존성이 없다.
- README 미리보기 슬라이드가 1280×720에서 잘리지 않고 읽힌다.
- 기본 데모와 실거래 차단 동작에는 변화가 없다.
