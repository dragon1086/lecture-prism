# lecture-prism 산출물 스타일

긴 결과를 사람이 읽고 바로 다음 행동으로 옮길 수 있게 만드는 공통 형식입니다. 한국어 문장은 저장소의 `fluent-korean` 스킬을 함께 적용합니다.

## 간결성 원칙

HTML은 내용을 많이 담는 문서가 아니라, 필요한 내용을 빨리 찾는 화면입니다.

- 첫 화면에는 결론 세 가지와 다음 행동 하나만 둡니다.
- 각 본문 영역은 `핵심 한 문장 → 근거 세 가지 이내 → 다음 행동 한 줄`로 줄입니다.
- 같은 내용을 요약·표·상세 영역에서 반복하지 않습니다.
- 일반 HTML 본문은 1,500자 안팎으로 끝냅니다. 원문 로그·전체 목록처럼 꼭 보존해야 하는 내용만 접힌 상세 영역에 둡니다.
- 표는 기본 5열 이내, 8행 이내로 줄이고 더 긴 자료는 `기타 N건`으로 묶습니다.
- 한 문장은 가능하면 25자 안팎으로 쓰고, 한 문단은 세 문장을 넘기지 않습니다.
- 배경 설명, 작업 과정을 다시 설명하는 문장, 의미 없는 서론은 생략합니다.
- 확인하지 못한 내용은 긴 변명 대신 `확인 필요` 또는 `추정` 한마디로 표시합니다.
- 핵심을 세 개로 줄일 수 있으면 네 번째부터는 쓰지 않습니다. 많이 아는 것을 보여 주는 일보다 다음 행동을 고르게 하는 일이 우선입니다.

## HTML로 만들 때

다음 중 하나라도 해당하면 Markdown만 길게 출력하지 말고 `reports/interactive/`에 독립 실행 HTML을 만듭니다.

- 결과가 800자 이상으로 길어질 때
- 표가 두 개 이상이거나, 같은 정보를 전후·단계별로 비교할 때
- 파일·함수·데이터 흐름처럼 접었다 펼쳐 보아야 할 내용이 있을 때
- 사용자가 나중에 다시 읽거나 다른 사람에게 보여 줄 가능성이 있을 때

파일 이름은 `YYYYMMDD-HHMM-짧은-이름.html` 형식으로 정합니다. 가능하면 이 문서와 함께 있는 `docs/lecture-prism-output-template.html`을 시작점으로 삼고, 외부 CDN·폰트·이미지·API 없이 HTML 한 파일 안에 CSS와 필요한 JavaScript를 넣습니다. 키·토큰·계좌번호·웹후크·개인 경로는 넣지 않습니다.

## 화면 구성

아래 순서를 기본으로 사용합니다.

1. 상단: 제목, 한 문장 요약, 생성 시각, 실행 프로필 또는 데이터 원천
2. 요약 영역: 상태, 핵심 결과, 확인이 필요한 문제를 세 칸 이내로 표시
3. 목차: 긴 결과라면 고정 목차를 둡니다.
4. 본문: 각 주제를 `<details open>` 영역으로 나누고 `핵심 → 근거 → 다음 행동` 순서로 씁니다.
5. 표: 열 수를 줄이고, 긴 문장은 셀 안에서 줄바꿈합니다. 숫자와 상태는 오른쪽 또는 가운데를 맞춥니다.
6. 하단: 확인한 사실, 아직 모르는 것, 다음에 할 한 가지를 분리합니다.

## 디자인 패턴

- 배경 `#0e101c`, 본문 `#f5f7fb`, 보조 글자 `#9ba3b6`을 사용합니다.
- 핵심 상태와 진행은 초록 `#73d99a`, 보조 강조는 보라 `#9da7ff`, 주의는 노랑 `#f0c16c`, 오류는 빨강 계열을 사용합니다.
- 기본 글꼴은 `Apple SD Gothic Neo`, `Pretendard`, `Noto Sans KR`, `system-ui` 순서로 둡니다.
- 둥근 카드와 색상 배지는 필요한 곳에만 사용합니다. 화면 전체를 카드 격자로 만들지 않습니다.
- 본문 폭은 1100px 안팎으로 제한하고, 제목은 한 줄 또는 두 줄 안에서 끝냅니다.
- `<details>` 열기·닫기, 본문 검색, 표 필터, 클립보드 복사는 결과를 줄이는 대신 다시 찾기 쉽게 하는 경우에만 넣습니다.
- 모든 버튼과 접이식 영역은 키보드로 사용할 수 있어야 하고, 색상만으로 상태를 구분하지 않습니다.

## 출력 순서

채팅에는 네 줄 안팎으로 다음만 남깁니다.

1. 결과 한 줄
2. HTML 파일 경로와 열어 보는 방법
3. 가장 중요한 확인 사항 한두 개
4. 남은 작업 한 가지

HTML 안에는 필요한 근거만 넣습니다. 상세 근거가 핵심 판단을 바꾸지 않으면 생략합니다. 아직 확인하지 않은 내용은 `확인 필요` 또는 `추정`으로 표시하고, 성공한 것처럼 쓰지 않습니다.
