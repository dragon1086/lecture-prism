# lecture-prism Strategy Harness Lite

이 리포지토리에는 수강생 전략을 실습 코드에 반영하기 위한 간단한 하네스가 들어 있습니다.

## 왜 넣었나

커리큘럼의 Part 4 목표는 “본인의 매매 이론 3줄을 코드에 넣어보기”입니다. 하지만 초보 수강생은 보통 이렇게 말합니다.

- “눌림목 같은 거요.”
- “손절 좀 빨리 하고 싶어요.”
- “뉴스 좋은 애만 보면 안 돼요?”
- “몰빵은 무서워요.”

Strategy Harness Lite는 이런 표현을 아래 네 트랙 중 하나로 정리하도록 돕습니다.

| 트랙 | 의미 | 파일 |
|---|---|---|
| A | 어떤 종목을 후보로 볼까 | `screening.py` |
| B | AI가 어떤 관점으로 분석할까 | `analysis.py` |
| C | 언제 팔까 | `trading.py` |
| D | 얼마나 보수적으로 운용할까 | `trading.py` |

## 구성 파일

| 경로 | 용도 |

| `.claude/agents/lecture-strategy-*.md` | Claude Code용 인터뷰어·구현자·검증자 역할 |

## 하네스가 자동으로 안 잡히는 것 같다면

코딩 에이전트가 하네스를 모르는 것처럼 답하면 아래 문장을 먼저 붙이세요.

```text
docs/harness-lite.md와 MY_STRATEGY.md를 먼저 읽고 Strategy Harness Lite 방식으로 진행해줘.
```

## 수강생이 쓰는 가장 쉬운 프롬프트

```text
MY_STRATEGY.md를 읽고 내 전략을 lecture-prism에 반영해줘.
내 설명이 부족하면 네가 먼저 합리적으로 정리하고,
진짜 꼭 필요한 질문만 하나만 해줘.
처음에는 Part 4 트랙 A/B/C/D 중 가장 안전한 것 하나만 골라서 수정해줘.
수정 후에는 API 키 없이 데모 모드로 실행 검증하고,
수정 전후 차이를 초보자도 이해하게 설명해줘.
실거래는 절대 하지 마.
```

## MY_STRATEGY.md를 안 써도 되는 프롬프트

```text
내 전략은 “거래량 터진 눌림목에서 들어가고, 손절은 짧게, 몰빵은 안 하는 방식”이야.
이걸 lecture-prism에 반영하려면 어디를 바꾸는 게 가장 안전한지 네가 판단해줘.
처음에는 한 파일만 수정하고, API 키 없이 데모 모드로 검증해줘.
```

## 하네스가 알아서 해야 하는 것

1. 수강생 말을 진입·분석·청산·리스크로 정리한다.
2. 가장 작은 수정 범위를 고른다. 전략이 여러 트랙에 걸치면 한 번에 다 바꾸지 않고, 한 트랙씩 [수정 → 검증 → 전후 비교] 사이클을 반복한다.
3. 함수 시그니처를 유지한다.
4. 실거래를 하지 않는다.
5. 데모 모드로 실행 검증한다.
6. 마지막에 변경 파일, 검증 결과, 다음 추천을 알려준다.
7. 한 트랙 검증이 끝난 뒤에만 System Completion Lane으로 같은 실행의 알림·주문·대시보드 증거를 맞춘다.

## 수업 빠른 모드 — 35분 안에 한 트랙 끝내기

수업에서는 **수업 빠른 모드**가 기본입니다. 목표는 거대한 자동매매 시스템을 한 번에 만드는 것이 아니라, 내 생각 하나가 코드와 결과에 실제로 반영되는 경험을 만드는 것입니다.

| 할 일 | 보통 걸리는 시간 |
|---|---:|
| `MY_STRATEGY.md`에 전략 3줄 적기 | 3~5분 |
| 하네스가 뜻을 정리하고 한 트랙 수정 | 10~15분 |
| API 키 없이 데모 검증 | 5~10분 |
| 전후 결과 읽기 | 약 5분 |

빠른 모드에서는 다음 순서로 진행합니다.

1. `MY_STRATEGY.md`, 트랙 지도, 이번에 바꿀 파일 하나만 먼저 읽습니다.
2. A/B/C/D 중 **한 트랙만** 수정합니다.
3. 관련 기능과 전체 mock 데모를 검증합니다.
4. 새 데이터 소스 조사, 여러 트랙 동시 수정, ETF·선물·코인 확장은 “다음에 할 일”로 남깁니다.

더 깊게 작업하고 싶을 때만 코딩 에이전트에게 `심화 모드로 이어서 해줘`라고 말합니다.

## Mac·Windows 공통 준비 확인

macOS와 Windows 모두 Python 3.10 이상이면 기본 실습을 진행할 수 있습니다. 운영체제별 명령어를 외우지 말고 Codex나 Claude Code에 아래 문장을 그대로 붙여넣으세요.

```text
내 컴퓨터가 macOS인지 Windows인지 먼저 확인해줘.
Python 3.10 이상이 설치되어 있는지 확인하고,
외부 패키지를 설치하기 전에 API 키 없이 lecture-prism 기본 데모부터 실행해줘.
경로나 한글 파일명 때문에 실패하면 내 운영체제에 맞게 고쳐서 다시 검증해줘.
실거래는 절대 하지 마.
```

Windows에서 선택 패키지 설치가 실패해도 기본 mock 데모는 계속 실행할 수 있어야 합니다.

## System Completion Lane — 전략 다음의 완성 증거

이 단계는 다섯 번째 전략 트랙이 아닙니다. A/B/C/D 중 한 트랙을 데모로 검증한 다음, 최신 `run_id` 한 건의 실제 `data_as_of`, 단계 `sequence`, Discord와 선택 Telegram 전달, 주문 접수·부분 체결·체결·차단, 대시보드가 서로 같은 실행을 보여주는지 확인합니다.

```text
내 전략 한 트랙의 데모 검증이 끝났어. 이제 System Completion Lane을 진행해줘.
같은 run_id의 data_as_of와 sequence, Discord와 설정된 경우 Telegram 전달,
accepted·partial_fill·filled·blocked·live_blocked 주문 상태,
대시보드의 분석·실제 filled_qty·교훈이 일치하는지 확인해줘.
시크릿 값은 출력하지 말고 실전 주문은 계속 차단해줘.
```

## API 키와 브로커 설정은 별도 트랙

Strategy Harness Lite의 목표는 **내 전략을 코드 한 곳에 반영하는 것**입니다. 실데이터, Perplexity, Firecrawl, KIS 모의투자 같은 외부 연결은 전략 하네스가 직접 섞어 처리하지 않습니다.

수업 이후 고급 설정까지 켜고 싶다면 먼저 [`docs/runtime-profiles.md`](runtime-profiles.md)를 보고 로컬 `.env`에 필요한 `KIS_PAPER_*` 값을 준비한 뒤, 코딩 에이전트에게 아래처럼 말하세요.

```text
내 전략 수정은 Strategy Harness Lite 방식으로 유지하되,
현재 .env 실행 단계와 KIS_PAPER_* 설정의 존재 여부도 함께 점검해줘. 값 자체는 출력하지 마.
전략 검증은 먼저 mock/simulation에서 통과시키고,
그 다음 내가 선택한 프로필이 real_data/research/paper/live 중 어디까지 실제로 켜지는지 설명해줘.
실제 주문 가능성이 있으면 먼저 차단 상태인지 확인해줘.
```

## 강사용 운영 팁

- 초반에는 `MY_STRATEGY.md`를 꼭 채우게 하지 않아도 됩니다. 말로 설명하게 하고 하네스가 정리하게 하세요.
- 35분 실습에서는 한 수강생이 한 트랙만 바꾸는 것이 좋습니다.
- 막히는 수강생에게는 “하네스에게 네 전략을 한 문장으로 말해보세요”라고 안내하면 됩니다.
- 실거래, KIS 인증, API 키 연결은 Part 4 실습 목표에서 분리하세요. 기본 검증은 데모 모드로 충분합니다.
